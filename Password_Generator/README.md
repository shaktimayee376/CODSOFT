#  Password Generator (Python GUI)
A simple and useful Password Generator built using Python and Tkinter.  
This tool helps users generate strong random passwords and copy them easily.
---

##  Features
- Generate strong random passwords
- User can set password length
- Includes letters, numbers, and special characters
- Copy password to clipboard
- Simple and clean GUI interface
---

##  Technologies Used
- Python
- Tkinter (GUI)
- Random module
- String module
---

##  How to Run
1. Make sure Python is installed
2. Download or clone the project
3. Run the file:

```bash
python password_generator.py
