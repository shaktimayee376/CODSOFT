# Password Generator

A Python-based password generator that creates strong random passwords.

## Features
- User-defined password length
- Includes uppercase letters
- Includes lowercase letters
- Includes numbers
- Includes special characters
- Input validation
- Exit option

## Requirements
Python 3.x
## Run
```bash
python password_generator.py
```
## Example
Enter password length: 12

Generated Password:
A8@kP2m#xL9!
