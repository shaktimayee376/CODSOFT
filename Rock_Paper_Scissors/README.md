# ✊📄✂️ Rock Paper Scissors Game (Python GUI)
A simple Rock Paper Scissors game built using Python and Tkinter GUI.  
This project allows the user to play against the computer with a simple and interactive interface.

---
## feature
- Simple GUI using Tkinter
- User vs Computer gameplay
- Score tracking system
- Random computer moves
- Reset game option
- Colorful and user-friendly interface

---
## 🛠️ Technologies Used
- Python
- Tkinter (GUI library)
- Random module

---
## 🚀 How to Run
1. Make sure Python is installed
2. Download or clone the repository
3. Run the file:
```bash
python game.py
