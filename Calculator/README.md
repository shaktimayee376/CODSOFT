# Pro Modern GUI Calculator
A modern scientific calculator built using Python and CustomTkinter. This project was created to improve my Python programming skills and gain hands-on experience with GUI development and Object-Oriented Programming (OOP).

## Features
* Modern and user-friendly interface
* Dark & Light Mode support
* Basic arithmetic operations
* Square Root (√)
* Power (^)
* Sine Function (sin)
* Error handling for invalid inputs

## Technologies Used
* Python
* CustomTkinter
* Math Module

## Run the Project
`bash
pip install customtkinter
python main.py

* Object-Oriented Programming (OOP)
